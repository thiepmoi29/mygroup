# Futuremo - Group Expense Management App

A professional Flutter application for managing group expenses with Firebase integration.

## 🛠️ Tech Stack

- **Framework**: Flutter (Dart)
- **Backend**: Firebase (Firestore + FCM)
- **State Management**: Streams
- **Local Storage**: SharedPreferences
- **UI**: Material Design 3

## 📁 Project Structure

```
lib/
├── models/           # Data models
├── services/         # Business logic (Firebase, Auth, etc.)
├── screens/          # UI screens
├── widgets/          # Reusable widgets
├── utils/            # Helper functions
└── main.dart         # App entry point
```

## 🚀 Getting Started

### Prerequisites

- Flutter SDK >= 3.0.0
- Firebase account
- Android Studio / Xcode

### Installation

```bash
# Clone repository
git clone https://github.com/thiepmoi29/mygroup.git
cd mygroup

# Install dependencies
flutter pub get

# Configure Firebase
flutterfire configure

# Run app
flutter run
```
